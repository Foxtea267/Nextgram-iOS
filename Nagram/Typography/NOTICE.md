# Optional fonts

No font binaries are bundled by this module. The optional download buttons fetch
the following unmodified fonts from Google Fonts revision
`cc39c4c2c304bc368c9b7c311ea2bcc6013299fe`, validating length and SHA-256:

- Source Sans 3: Adobe; SIL Open Font License 1.1.
  [License](https://github.com/google/fonts/blob/cc39c4c2c304bc368c9b7c311ea2bcc6013299fe/ofl/sourcesans3/OFL.txt)
- Noto Serif SC: The Noto Project Authors; SIL Open Font License 1.1.
  [License](https://github.com/google/fonts/blob/cc39c4c2c304bc368c9b7c311ea2bcc6013299fe/ofl/notoserifsc/OFL.txt)

Downloads are explicit user actions. The settings page links to each license
before downloading. Imported fonts remain subject to their own terms; a settings
backup contains selections only, never font bytes.
