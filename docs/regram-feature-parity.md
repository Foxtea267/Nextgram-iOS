# Regram 功能对照

以 [Regram 的功能清单](https://github.com/RegramDev/Regram-ios/blob/67c4050ea0c33d1c12e0e89a1e20bc36c839d35d/docs/features.md) 为参考。这里记录 Nextgram 的实现范围与待补功能。

| 范围 | Nextgram 已有 | 还需补齐或对照验证 |
| --- | --- | --- |
| 设置与外观 | 首页搜索、底栏自定义、截图徽章及垂直偏移、独立图标、本地会员星标 | 原生设置页统一搜索、字体管理、更多个人资料展示 |
| 更新 | 四种 IPA 匹配、下载校验与缓存、自动检查、证书导入、本机重签、iOS 安装交接 | 真机覆盖安装验证、TrollStore、后台下载、签名包跨重启缓存和灵动岛进度 |
| 聊天管理 | 聊天筛选与排序、最近聊天、消息菜单、双击动作、部分分组设置、消息书签与标签、取消置顶确认、管理操作预选、群组及频道本机备注 | 本地不限置顶、共同群组发言、首次启动发送任务 |
| 过滤与通知 | 删除消息拦截、规则过滤、幽灵模式、已删除记录导入导出、通知诊断 | 群内定向屏蔽、成员特别提醒、通知内容和置顶策略的逐项对照 |
| 输入与媒体 | 默认消息格式、编辑历史、音乐播放列表搜索、媒体信息、自动显示剧透、隐藏快捷转发按钮 | 本地音频作为语音发送、编辑历史图片版本、贴纸包备份、单条消息截图 |
| 翻译与网络 | 多服务翻译、LLM 翻译、语音转文字、Telegram 延迟测试 | 消息总结、网页翻译、网络与传输选项、链接预览规则的逐项对照 |
| 账号与本地展示 | 可选账号数量无上限、会话备份、扫码登录、资料 ID、DC、会员星标 | 按类别设置备份、清理本地数据、礼物与个人资料模拟 |

消息书签在设置首页的「收藏夹」下方，从消息长按菜单新增。书签按账号保存在本机，可以筛选标签、修改、移除和定位到原消息。记录包含消息位置和用户输入的标签，原消息能否打开取决于 Telegram 的访问权限。

从已加入的群组或频道的资料页「更多」菜单设置本机备注。备注会显示在聊天列表、聊天标题和本机搜索结果中，清空可恢复原名称。

频道信息流可从 Nextgram 设置首页或底栏「聊天」的长按菜单打开。它汇总当前账号加入的频道，支持归档频道、选择来源、自建分类、自动纳入新频道、仅看未读和打开原帖。

自动显示剧透、隐藏快捷转发、取消置顶确认和预选管理操作默认关闭。预选仅影响原生删除确认面板上可用的操作。用户仍需确认才会执行。

Nextgram 的 Extera 插件另见[兼容范围](extera-plugins.md)。
