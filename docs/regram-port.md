# Regram 功能对照

对照 [Regram 13.2 b34652 的公开清单](https://github.com/RegramDev/Regram-ios/blob/ff561aa7504d85caf2bfffbc981667d992a9f483/docs/features.md)。此表区分源码已接线与尚待移植；未做完整 iOS 构建或设备回归的项目不视为已通过验收。

单会话删除拦截和群内隐藏名单按账号及会话保存在本机。隐藏成员的消息仍留在 Telegram 和本机数据库，服务端不会收到屏蔽请求。复制的 DC 测量结果不包含代理地址或账号标识。

「隐藏动态浏览记录」默认关闭，也随幽灵模式生效：阻止普通动态读状态与资料置顶动态浏览计数上报，并丢弃开启时尚未发送的排队上报。不把隐身观看改写为本地已读，关闭后不会把隐身期间记录补发；后续重新观看仍按当时设置处理。已经发出的请求／浏览记录无法撤销，回复、点赞等主动操作不隐藏。

编辑历史每条消息最多 50 个旧版本，超限保留最初版本与最近 49 个版本，兼容原来的纯文字记录。只有开启保存后在本机收到的修改才能记录，自己的编辑也在旧内容覆盖前保存。已缓存图片可独立保留最多 8 MiB/版本、32 MiB/消息；预算不足优先保留最初和较新的图片，文件等其他媒体仍受引用有效期与缓存清理影响。历史图片按最大 2048 像素解码，避免压缩图的超大尺寸造成内存风险。当前版本在前、旧版本从新到旧排列，旧媒体使用独立画廊，历史 Instant Page 使用保存的页面打开原生浏览器，不修改当前聊天内容。历史富文本复制保护及嵌入媒体回归仍待补齐。

重新拉取消息时，数据库属性合并会保留编辑历史与删除标记；明确传入的新历史优先于已有副本，避免覆盖编辑更新。另补齐了上游收紧 Postbox 可见性后既有消息历史模块缺少的依赖权限。

共同群组发言现已移除前 100 群限制，分页获取共同群组并保存每群消息搜索游标；支持关键词、单群筛选、加载更早消息、暂停／继续和超时重试。普通状态最多 3 路搜索，低电量或严重高温降为 1 路，临界高温、后台及离开页面暂停，返回后手动继续。群组选择改为可搜索名称／ID 的原生列表，支持所有群组及当前选中标记，不再给每个群创建一项操作表按钮。尚需对照 Regram 的原生消息单元与下拉刷新。

服务器测试改为手动开始，可在离开页面、后台及已连接代理地址变化时取消。DNS 部分重新查询 Cloudflare／Google 的 A、AAAA 并验证 DNS JSON 成功结果，显示地址及端到端请求耗时；并非 Telegram 生产解析器测量，尚未接入自定义网络策略。复制结果保持仅 DC 平均值，不带代理或账号信息。

本地音频转语音适配 Regram 的流式 FFmpeg→48 kHz 单声道 Ogg/Opus 路径，支持取消及一小时限制，生成原生语音草稿，不自动上传或覆盖已有媒体／编辑草稿。本机音频库单曲也可选择转换；带说明文字、静默或定时的路径保持原文件发送，以免转换时丢失意图。贴纸／表情包预览菜单支持导出原始文件与有序 emoji 清单 ZIP，最多 500 个文件、32 MiB/文件及 256 MiB/包，取消与失败清理临时文件。尚未执行 iOS 编译或设备测试；分发前需核实派生来源许可，见 `Nagram/VoiceMessages/NOTICE.md`。

通知的置顶、提及、回复事件可分别保留原生行为、静默或关闭；主程序与通知扩展通过 App Group 共用策略、隐藏名单和成员特别提醒名单。成员特别提醒仅在用户逐个启用后对该账号、该群的新未读发言覆盖群静音；已读、导入、自己的消息、服务消息、离群和过滤内容不恢复，静默发送及预览隐私不改变。扩展只增强实际收到且成功解析的推送，不承诺唤醒已被系统挂起的 App；通知授权与专注模式仍由 iOS 控制。成员名单保存在本机，不随通用设置备份跨账号恢复。

Apple Music 样式的队列改为独立覆盖层：播放器留在底下，列表打开与收起用 0.38 秒无过冲过渡，减少动态效果时改为淡入淡出；返回、关闭和下拉只收起队列。封面点击进入可缩放详情，显示歌曲和艺人；可选 3D 按压、拖动倾斜、相对陀螺仪视差及反光，后台／不可见／减少动态效果时停止，不记录或上传传感器数据。动效属于原创实现，并非 Spotify 二进制或私有接口移植，尚未完成 iOS 逐帧验收。

配置备份增加字体选择、通知策略和独立总结配置；不包含字体文件、总结 API 密钥，恢复总结配置后默认保持关闭，避免把配置恢复当成向第三方上传消息的同意。

系统音乐显示增加「始终／仅后台／不显示」选项，使用公开 Now Playing 接口，同时影响灵动岛、锁屏和控制中心的音乐卡片与遥控命令，不改变音频引擎或后台播放。没有公开接口可仅关闭音乐灵动岛而保留完全一致的系统卡片。源码没有指向 Xsign 的播放跳转；签名后点击卡片打开其他 App 的问题仍需检查实际安装包的身份与注入，不能以关闭卡片冒充归属问题已修复。

播放器菜单和设置页均可即时切换系统音乐显示。封面异步完成后统一保留当前播放时钟和倍速，不再用纯封面字典覆盖进度。队列进出期间保持辅助功能焦点在覆盖层，关闭旧样式时清除模态状态。

已签名更新包缓存包含原始发行包哈希、签名材料指纹、构建号、签名包长度和 SHA-256。恢复时先验证原始发行包，再检查缓存与当前证书／描述文件一致且未过期；不符则回到待签名状态。签名材料仍只在本机钥匙串，不上传；清理更新缓存同时清理签名包。此路径尚未进行重启／覆盖安装的设备回归。

频道信息流修复多行正文与日期重叠（日期原来错误地复用了正文起点），日期现在排在完整预览之后；新增默认开启的自动加载，可在信息流操作菜单及聊天设置关闭。接近底部或「加载更多」行可见时分页，请求期间防重入，失败保留重试，离开页面与后台取消，关闭开关后保留手动加载。

本轮验证：针对改动的 Swift tree-sitter 语法解析及 BUILD AST 检查通过；增加了旧格式解码、格式／媒体序列化、内容比较、50 版本保留原始项、媒体 ID 关联、去重和刷新保留属性的 XCTest 用例，尚未执行。Windows 环境缺少 Swift、Bazel 和 Xcode，未完成完整 App 构建、模拟器录屏或视觉验收。

视觉验收预期：历史列表当前版本置顶，日期与正文不重叠，长文本及大字体可滚动；浅／深色均可读；点击旧媒体先关闭历史页再打开独立画廊，退出后当前消息不变。规则测试结果应在输入弹窗关闭后显示，含 emoji 和重叠匹配时不截错文字。媒体网格切换设置后应即时增减剧透遮罩，敏感内容仍保持原有确认行为。这些路径仍需在 iOS 上录屏并按帧检查。

后续视觉验收预期：播放列表打开时播放器留在下层，覆盖层约 0.38 秒向上进入、不回弹；收起只关闭列表，过程中触摸不得穿透。封面详情打开／关闭不退出播放器，双击和捏合可放大，缩放后平移不被按压手势抢走。成员提醒列表移除后即时刷新；共同群选择器在浅／深色及大字体下均不截断，取消不修改筛选。当前环境无法录制 iOS 模拟器，以上均为验收标准而非已通过的视觉结果。
