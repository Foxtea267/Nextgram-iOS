# Regram 功能对照

对照 [Regram 13.2 b34652 的公开清单](https://github.com/RegramDev/Regram-ios/blob/ff561aa7504d85caf2bfffbc981667d992a9f483/docs/features.md)。此表区分源码已接线与尚待移植；未做完整 iOS 构建或设备回归的项目不视为已通过验收。

| 范围 | Nextgram 已有或已接线 | 仍需补齐或核对 |
| --- | --- | --- |
| 消息与会话 | 本机置顶、最近会话、群和频道备注、书签、消息菜单与双击、作者发言查询、共同群组发言、文本编辑历史。复读后定位到最新消息。 | 富文本与图片编辑历史、共同群组与作者查询的分页及筛选对齐、更多分组操作、每日首次启动发送。 |
| 过滤与隐私 | 删除拦截、黑白名单、编辑历史、已删除记录导入导出、正则规则、幽灵模式；支持长按聊天头像为当前会话单独设置删除拦截，自定义或隐藏删除标识。 | 逐项核对规则测试、临时恢复、动态浏览隐私、置顶与提及通知策略。 |
| 群内管理 | 长按成员头像可仅在当前群隐藏其消息；长按聊天头像可打开恢复列表。应用内和本地兜底通知过滤同一名单。 | 群资料入口、聊天列表及搜索的过滤、独立成员特别提醒、通知扩展的 APNs 过滤。 |
| 翻译和语音 | LLM 翻译、语音转写设置、原有翻译路径。 | 独立消息总结及上传确认、服务商覆盖、网页翻译控制、圆视频及聊天上下文的逐项回归。 |
| 媒体与链接 | 现有链接预览修复、媒体信息、贴纸尺寸、播放与相机选项。 | 贴纸 ZIP、音频作为语音发送、截图版式、相册多视频角标、锁屏暂停与画中画验证、加载试验。 |
| 外观与输入 | 分组设置与搜索、图标与勋章、底栏编辑、盘古之白、默认格式；显摆页提供本地会员、手机号、评级、星币与 TON 的设置。 | 字体下载导入与回退、底栏高度和入口随图标同步、富文本各路径回归、本地礼物及装扮、原生 TON 卡和角色徽章。 |
| 网络与诊断 | 当前账号 MTProto 往返；DC1–DC5 独立 worker，首次请求和三次采样，展示平均、最低、波动和失败次数，支持停止和复制。 | DNS／DoH 与 IP 策略、代理候选地址轮换、DNS 测试、媒体传输统计、过滤性能诊断；需真机实测代理和各 DC。 |
| 登录、备份、更新 | 本机账号上限开关、分类设置备份、自签更新、独立发布身份与构建流程。 | 二维码登录兼容性、后台续传与实时活动、TrollStore 交付、更新缓存清理和额外安装流程。 |

单会话删除拦截和群内隐藏名单按账号及会话保存在本机。隐藏成员的消息仍留在 Telegram 和本机数据库，服务端不会收到屏蔽请求。复制的 DC 测量结果不包含代理地址或账号标识。
